# 芯片手册

| 目录 | 资料用途 |
| --- | --- |
| `STM32F446` | MCU数据手册与参考手册 |
| `ESP32C3` | ESP32-C3-MINI-1规格与硬件设计指南 |
| `WM8960` | Codec寄存器、时钟与模拟音频说明 |
| `ST25DV` | ST25DV04K存储、NDEF与mailbox说明 |

这些PDF是硬件和驱动联调参考，不由软件构建系统读取。

STM32参考手册用于外设和时钟配置；WM8960手册用于I²S/寄存器和模拟音频；ST25DV手册用于I²C地址、容量和NDEF/mailbox；ESP32资料用于供电、复位、天线与下载线路设计。
